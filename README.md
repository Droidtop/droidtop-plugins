# droidtop-plugins

Archived. This repository never held anything: the droidtop plugin index lives in
[Droidtop/droidtop-platforms](https://github.com/Droidtop/droidtop-platforms),
at `droidtop-plugins/index.json` (with `droidtop-plugins/revocations.json` beside
it), which is the path droidtop reads. The index format and the signing scheme
are specified in droidtop's docs/SPEC.md (plugins).
