# droidtop-plugins

The public plugin index for [droidtop](https://github.com/Droidtop/droidtop).

A plugin repository publishes plugin bundles and signs them with its own repository key. droidtop trusts
a repository's key when the user adds that repository, and a plugin from it is shown as
"Verified by: (repository name)". Anyone can run their own repository; this one is the default index.

This repository is being set up. The index format and the signing scheme are specified in droidtop's
docs/SPEC.md (plugins). Nothing here is published yet.
